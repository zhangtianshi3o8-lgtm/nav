# GitHub 精选导航 (nav.3o-8.com)

> 中文开发者的开源项目指南。人工精选，静态发布，数据由 GitHub API 核实。

## 收录分类

- AI 与大模型：本地跑模型、聊天界面、知识库编排、绘图、语音
- 前端开发：框架、构建工具、组件库
- 后端与 API：各语言 Web 框架、调试工具
- 自托管服务：相册、云盘、密码、影视、监控、笔记
- 运维与 DevOps：面板、网关、监控、容器编排
- 学习资源：算法、面试、路线图、系统设计
- 命令行工具：现代 CLI 替代品、终端增强
- 中文原创精品：国内团队/作者的主力开源项目

## 项目数据

- 每个项目给出：中文名称、一句中文导读、星数、主语言、最近推送日期
- 「停更」标记 = 最近推送超过一年；「近一年低活跃」= 6~12 个月无推送
- 星数与日期由 GitHub API 实时拉取，非人工填写

## 维护方式

收录清单在 `data/seed.json`（仓库全名 + 分类 + 中文导读）。更新流程：

```
# 1. 编辑 data/seed.json 增删项目
# 2. 拉取核实数据
python3 scripts/fetch_repos.py
# 3. 重新生成页面
python3 scripts/build.py
# 4. 发布
git add -A && git commit -m "update" && git push
```

页面自动带上当天日期作为更新戳。
